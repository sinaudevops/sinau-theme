# Features Guide — Sinau-theme

This document details the custom features implemented in the "Sinau-theme" for developers and content creators.

## 1. Copy to Clipboard (Code Blocks)

The theme automatically adds a "Copy" button to every syntax-highlighted code block generated by Hugo (Chroma).

### How it Works
- **Automatic Injection**: JavaScript detects all `div.highlight` elements and injects a minimalist button.
- **Smart Copy**: It is designed to copy only the code content, correctly handling both standard layouts and line-number table layouts.
- **Visual Feedback**: The icon changes to a checkmark for 2 seconds upon successful copy.

### Customization
You can customize the button appearance in `assets/scss/components/_copy-code.scss`:
- **Position**: Adjust `top` and `right` values in `.copy-code-button`.
- **Colors**: Change the `background`, `border`, and `color` properties.
- **Success Feedback**: Modify the `.copy-code-button.copied` class for different success colors.
